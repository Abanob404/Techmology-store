# V9.3 Stable Mobile UI

- Main mobile navigation no longer auto-hides or slides while scrolling.
- Main mobile navigation is centered using left/right anchors with no translate transform.
- Mobile top header is fixed and has no movement transition.
- Product Buy / Cart / WhatsApp actions are now part of the product details flow instead of a viewport-fixed floating bar.
- Removed the extra bottom spacing that was only needed for the floating product action bar.
- Existing V9.2 campaign link and admin sizing improvements are preserved.
