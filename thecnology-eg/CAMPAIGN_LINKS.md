# روابط الحملات المختصرة

يدعم المتجر روابط نظيفة بدون UTM ظاهر، مثل:

- `/facebook` — الرئيسية / Facebook
- `/instagram` — الرئيسية / Instagram
- `/whatsapp` — الرئيسية / WhatsApp
- `/facebook-products` — صفحة المنتجات / Facebook
- `/instagram-services` — صفحة الخدمات / Instagram
- `/facebook-products-launch` — صفحة المنتجات / Facebook / حملة launch
- `/qr-launch` — الرئيسية / QR / حملة launch

المصدر والحملة يتم التقاطهما تلقائياً داخل تحليلات المتجر.
